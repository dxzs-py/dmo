> 本手册将两份 Redis 源文档（原版 96.5KB + 增强版 157.9KB，共 254.4KB）系统性重构为 **22 篇**结构化文档（含《跨平台差异_Windows与Linux.md》），遵循与 Node.js 23 篇 / Docker 19 篇 / PostgreSQL 21 篇一致的格式规范，重点覆盖项目开发与 Agent 开发（LangChain 1.x）。

## 四、术语表

| 术语 | 解释 | 出处 |
|------|------|------|
| 单线程模型 | Redis 命令执行在单线程，避免上下文切换与锁竞争 | 01 |
| IO 多线程 | Redis 6.0+ 网络 IO 多线程，命令执行仍单线程 | 01 |
| RESP3 | Redis 序列化协议第 3 版，支持推送与客户端缓存 | 01 |
| SDS | Simple Dynamic String，Redis 自定义字符串 | 02 |
| listpack | Redis 7.0 紧凑列表编码（替代 ziplist） | 02 |
| skiplist | 跳表，ZSet 底层结构 | 02 |
| RDB / AOF | Redis 两种持久化机制 | 03 |
| 混合持久化 | RDB + AOF 增量，兼顾恢复速度与数据安全 | 03 |
| Copy-On-Write | 写时复制，RDB fork 利用机制 | 03 |
| LRU / LFU | 最近最少使用 / 最少频率使用淘汰策略 | 04 |
| 内存碎片率 | used_memory_rss / used_memory，应接近 1 | 04 |
| 全量同步 / 增量同步 | 复制两种方式，增量用 replication backlog | 05 |
| Sentinel | 哨兵，监控主从并自动故障转移 | 05 |
| quorum | 判定客观下线所需哨兵数量 | 05 |
| 哈希槽 | Cluster 共 16384 槽，CRC16(key) % 16384 | 06 |
| Gossip | Cluster 节点间通信协议 | 06 |
| MULTI/EXEC | Redis 事务开始与提交 | 07 |
| WATCH | 乐观锁，监视键变化 | 07 |
| EVALSHA | 执行缓存 Lua 脚本（SHA1） | 07 |
| Pub/Sub | 发布订阅模式 | 08 |
| Stream | Redis 5.0 消息流数据类型，支持消费者组 | 08 |
| 消费者组 | Stream 消费组，支持 ACK 与待处理消息 | 08 |
| Cache Aside | 最常用缓存模式：先 DB 后删缓存 | 09 |
| 缓存穿透 | 查询不存在数据绕过缓存 | 09 |
| 缓存击穿 | 热点 key 过期瞬时高并发 | 09 |
| 缓存雪崩 | 大量 key 同时过期 | 09 |
| Redlock | 多节点投票分布式锁算法 | 10 |
| Pipeline | 批量命令减少 RTT | 11 |
| 大 Key | 单 key 内存占用过大（>10KB Hash/List） | 11 |
| ACL | Redis 6.0+ 访问控制列表 | 12 |
| RedisVL | Redis 向量库客户端库（Python） | 16 |
| RediSearch | Redis 全文搜索与向量检索模块 | 16 |
| ChatMessageHistory | LangChain 对话历史存储抽象 | 17 |
| MCP | Model Context Protocol，AI 工具协议 | 18 |

## 五、环境准备

### 5.1 Redis 服务端

```bash
# 本手册以 Redis 8.x 为基准（8.0 起内置 RediSearch/Search/JSON 模块与 Vector Sets，无需 Redis Stack）
# Docker 快速启动（端口与本机 6379 冲突时改用 6380，见 codes/README）
docker run -d --name redis-dev -p 6379:6379 redis:8.2-alpine

# 验证（Redis 8 起支持 RESP3；输出应含 redis_version: 8.x）
redis-cli ping              # PONG
redis-cli info server | grep redis_version
```

### 5.2 Python / LangChain 环境

```powershell
conda activate agent_develop   # 本项目实测环境；也可用 langchain_xm（均需 langchain 1.x）
pip install "redis>=8.1" redisvl "langchain>=1.4" "langchain-redis>=0.2.5" langchain-openai
```

### 5.3 Node.js 环境

```powershell
nvm use v20.19.5
npm install ioredis redis
```

### 5.4 Django 环境

```powershell
pip install "Django>=5.2" django-redis "redis>=8.1"
```
