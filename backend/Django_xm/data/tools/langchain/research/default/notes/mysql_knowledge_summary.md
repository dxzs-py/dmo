# MySQL 知识库总结

## 1. 知识体系总览
MySQL的知识体系可以分为以下几个层次：

- **基础层**：连接操作、SQL语法、数据类型、约束
- **原理层**：分层架构、InnoDB引擎、B+树索引、Buffer Pool、Doublewrite Buffer、Change Buffer、AHI
- **事务层**：ACID特性、隔离级别、MVCC、Redo/Undo Log
- **锁层**：全局锁、表锁、行锁、Next-Key Lock、死锁
- **高级层**：视图、触发器、存储过程、分区、窗口函数、CTE
- **优化层**：EXPLAIN、索引优化、SQL调优、慢查询、参数调优、连接池、分库分表
- **应用层**：电商、SaaS、日志、社交、金融、分析、CMS

## 2. 分库分表策略
分库分表的策略选择主要有两种：

- **垂直分库**：按业务拆分，例如：用户库、订单库、商品库。
- **垂直分表**：按列拆分（冷热分离），例如：将用户表拆分为核心信息和详细信息。
