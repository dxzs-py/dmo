## 一、知识库 test1：MySQL 知识体系分析

### 1.1 概述
test1 是一个全面系统的 **MySQL 数据库知识体系库**，内容覆盖从基础操作到底层原理、从日常运维到高级优化的全链路知识。以分层结构组织，层次清晰。

### 1.2 核心知识层次

| 层次 | 核心内容 |
|------|---------|
| **基础层** | 连接操作、SQL 语法、数据类型、约束 |
| **原理层** | 分层架构、InnoDB 引擎、B+树索引、Buffer Pool、Doublewrite Buffer、Change Buffer、AHI |
| **事务层** | ACID 特性、隔离级别、MVCC、Redo/Undo Log |
| **锁层** | 全局锁、表锁、行锁、Next-Key Lock、死锁 |
| **高级层** | 视图、触发器、存储过程、分区、窗口函数、CTE |
| **优化层** | EXPLAIN、索引优化、SQL 调优、慢查询、分库分表 |
| **应用层** | 电商、SaaS、日志、社交、金融、分析、CMS 场景 |

### 1.3 关键技术亮点
- **InnoDB 引擎核心**：Buffer Pool 管理、Doublewrite Buffer（解决部分写）、Change Buffer（优化二级索引写）、自适应哈希索引 AHI
- **事务与 MVCC**：ACID 实现、4 种隔离级别、MVCC 多版本控制、Redo/Undo Log 协同
- **锁机制**：Next-Key Lock 解决幻读、死锁场景与解决策略
- **复制高可用**：Binlog 三种格式（STATEMENT/ROW/MIXED）、半同步复制（RPO≈0）、延迟从库
- **备份恢复**：mysqldump 逻辑备份、xtrabackup 物理备份、Binlog 时间点恢复
- **性能优化**：慢 SQL → EXPLAIN → 定位 → 优化闭环、索引设计原则

### 1.4 适用人群
- 初中级开发者：夯实 SQL 基础与索引优化
- 高级开发/架构师：原理层深入与高可用设计
- DBA：备份恢复、监控调优、容灾方案

## 二、知识库 test2：Redis 知识体系分析

### 2.1 概述
test2 是一个系统化的 **Redis 知识体系库**，涵盖基础数据结构操作、安全配置、性能优化、持久化、高可用架构、消息队列及高级特性。注重实操性，提供大量命令示例。

### 2.2 核心知识模块

| 模块 | 核心内容 |
|------|---------|
| **安全配置** | 设置强密码、禁用敏感命令（FLUSHDB/FLUSHALL/DEBUG） |
| **性能优化** | 慢查询日志（slowlog）、内存分析（MEMORY DOCTOR/USAGE） |
| **复制与持久化** | 主从复制配置、RDB 压缩与校验 |
| **GEO 位置服务** | 地理坐标添加（GEOADD）、附近搜索（GEOSEARCH） |
| **热 Key 与缓存策略** | 热 Key 处理、缓存穿透/击穿/雪崩解决方案 |
| **Pub/Sub 与 Stream** | 发布订阅、Stream 消息队列（XGROUP/XADD/XREADGROUP） |
| **集群与哨兵** | Redis Cluster 数据分片、哨兵自动故障转移 |
| **数据结构** | Set/Sorted Set/List 操作与复杂度分析 |
| **高级特性** | Lua 脚本、多线程 I/O（Redis 6.0+）、Listpack 与 hashtable |
